# FitCoach-LLM

Project for the AI course

## Requirements

- Python 3.13+
- Streamlit `pip install streamlit`
- Mistral API Key

## How to use

Create a `.env` file and complete it with `MISTRAL_API_KEY='your_Mistral_API_Key'`.

Install python librairies:

```
pip install -r requirements.txt
```

Run the app:

```
streamlit run app/app.py
```
